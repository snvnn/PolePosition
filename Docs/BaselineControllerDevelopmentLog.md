- 최초 신규 Rust 테스트 소스의 소수 리터럴 구문 오류를 수정한 뒤 재실행했다. clippy의 중첩 if 지적도 수정했다. 실패를 실제 주행 실패로 해석하지 않는다.
- [오프라인 검사](../baseline_runs/offline-1790825566587823500-14704/validation.json): 원본 182,992관측의 상태·시작 조건을 검사했다. 기준 경로 3,886점 중 66점은 ±0.15 조향 한계 밖이다. 가장 큰 요구량 0.2769이므로 전체 코스를 현 설정으로 완주한다고 주장하지 않는다.
- 동일 근사 조향 계수를 사용한 단순 가상 차량 3회는 30초 종료, 각 36.84m 이동. 경로 오차 최대 0.0416/0.0102/0.0162m. 실제 ACC 속도·오차 성능이나 안정성 검증이 아니다. 원본 해시 재확인 완료.

## 2026-10-01 — 사용자 요청: 한 바퀴로 고저차 반응 수집

- 속도 계수를 먼저 조정하기보다 한 바퀴 데이터로 고저차 대응을 보자는 요청에 따라 작업 순서를 변경했다. 아웃랩 시간을 넉넉하게 두라는 추가 요청을 반영해 제한 60분·출발 전 대기 10분으로 설정했다.
- [한 바퀴 설정](../BaselineController/lap.toml)을 추가했다. 기존 30초 설정은 보존했다. 같은 추적 구간에서 출발 위치부터 모델 전체 길이를 진행한 뒤 정지하며, 시간 종료와 경로 한 바퀴 완료를 구분한다.
- 기준 Y 높이 범위는 −21.942~12.955m(차이 34.897m)다. 기존 Y 기록과 함께 경로 앞뒤 5m 기반 경사, 목표·관측 속도, 요청·전송·관측 페달, 경로 진행과 게임 랩 정보를 남긴다. 경사는 피드백/선행 보정 입력에 새로 넣지 않았다.
- 전방 8m·PID 계수는 유지했다. 모델 요구량 0.2769를 바탕으로 한 바퀴 설정에 조향 상한 0.35를 고정했으며, 가속 상한 0.20은 기존 감시기의 허용 범위다. 실제 더 큰 조향 응답은 이번 시험에서 확인한다.
- [오프라인 검증](../baseline_runs/offline-1790826889941566200-21268/validation.json): 원본 182,992관측 재검사·입력 해시 불변, 경로 3,886점 전부 설정된 조향 범위 이내. 이상적인 고정 속도를 사용하는 평면 모의 추종이 한 바퀴 종료에 도달했고 최대 경로 오차 0.108m였다. 경사·ACC 차량 역학 검증이 아니다.
- 신규 한 바퀴 종료·시간 초과·짧은 모드 제한 보존·경사 부호/순환 검사 통과. 보고서 시험의 합성 입력에서 브레이크 필드를 빠뜨려 처음 실패했고 필수 관측을 보완한 뒤 Python 입력 모듈 16개를 통과했다. 실제 원본 누락 문제가 아니다.
- 이 시점에는 **실게임 한 바퀴 수행 대기**였다. 아래에 실제 수행 결과를 추가했다. 실패 시 중간 구간을 완주 데이터로 합치지 않으며, 장치 장애 대응은 사용자 요청대로 후속 미해결 과제로 유지한다.
