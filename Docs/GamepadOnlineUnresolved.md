# 연속주행 IQL의 미확인 사항

기존 `OutcomeLearningUnresolved.md`를 확장하는 별도 문서다. 원본 문서는 기존 모델의 해시 계보에 포함되므로 수정하지 않았다.

- 정확한 위빙 시작·종료 경계: 기존 전체 기록 격리 목록만 유지한다.
- 랩 무효화의 물리적 원인: 텔레메트리의 유효→무효 사건만 확인하며 조향/속도/트랙 경계를 원인으로 단정하지 않는다.
- 자동 재배치의 원인: 사용자 조작 또는 게임 처리로 추정하지 않는다. 재배치 전 종료 관측과 재배치 후 정차 증거를 별도로 요구한다.
- 보상 계수의 최적성: 기존 B 계수를 유지했으며 안정적 완주에 최적이라고 검증한 것은 아니다.
- 외부 게임의 정확한 입력 적용 시각: 가상 패드 전송 시각을 실제 게임 적용 시각으로 표현하지 않는다.
- 실제 새 경험의 학습과 다음 F7 적용, F8의 실게임 단계별 반응, 재배치 후 장치 해제: 자동 검사만 수행했다. 사용자가 이번 범위를 코드·오프라인 검증으로 제한하여 실게임 검증은 남아 있다.
- 3랩 × 3회 무개입 유효 완주: 아직 평가하지 않았다. 단발 완주, 오프라인 MSE, TD 오차 또는 저장 성공으로 대신 판정하지 않는다.
- 장시간 최대 규모의 실게임 기록 검증 처리량과 학습 진전: 실제 회차 기록으로 확인해야 한다. 진전이 없을 때 탐색/알고리즘/격리 경계를 임의로 바꾸지 않는다.
