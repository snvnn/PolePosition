# 저속 교사 모방 학습 개발 기록

## 2026-10-01 — 착수

- 사용자 승인 범위: 기존 PID 교사의 가감속 모방, 오프라인 학습·재개·평가, Rust 추론, shadow 후 모델 입력 5/10/15초 시험.
- 기존 한 바퀴를 train으로 사용하고 새 30초 교사 실행 3회를 train 보강 / validation / test로 수집 전에 배정했다. [배정](../ModelTrainer/sources.toml).
- 고속 사람 5랩(72.6~239.7km/h)은 혼합하지 않는다. 사람 모방학습·강화학습이나 PID 개선을 완료로 처리하지 않는다.
- Rust 특징 계산과 작은 MLP 추론 라이브러리를 시작했다. 별도 Python 가상환경을 사용하며 기존 전역 환경과 원본 기록은 변경하지 않는다.
- 추가 주행과 모든 학습/검증 결과는 아직 미수행이다. 구현과 실제 검증을 구분해 이어 기록한다.

## 2026-10-01 — 초기 특징·학습 점검과 교사 수집

- Rust 특징 계산 4개 검사 통과. 100/200/500ms 과거 조회, 미래 대체 금지, 중복·시간 역전·공백 초기화, 출력 페달 상호 배타성을 확인했다.
- 별도 환경에 PyTorch 2.8.0+cpu / NumPy 2.3.3을 설치했다. 최초 격리 환경의 네트워크 차단으로 설치가 실패했고, 승인된 외부 네트워크 접근으로 완료했다. 설치된 전이 의존성도 lock 파일에 고정했다.
- 첫 자료 준비는 Windows 확장 경로(`\\?\`)와 일반 경로의 문자열 차이로 실패했다. `samefile`로 실제 파일을 비교하도록 수정한 후 성공했다. 실패 산출물은 미완료로 보존했다.
- 기존 한 바퀴로 3 epoch smoke 학습 267회 갱신을 실행했다. 마지막 손실 0.0016291이며 같은 train으로 동작만 확인한 값이다. 독립 검증이나 실게임 진입 근거가 아니다. [학습](../training_runs/smoke-1790830561446469200-6fb095ce/summary.json).
- 첫 교사 시도는 격리 실행 환경에서 ACC 전면·F7이 감지되지 않아 `arm_timeout`, 주행 입력 0으로 종료됐다. [미시작 기록](../actuator_runs/demo-1790830459276174500-15576/summary.json). 실제 사용자 세션으로 재실행하니 전면·F7을 정상 감지했다.
- 교사 1회(train 보강): [실행](../actuator_runs/demo-1790830606855790900-16496/summary.json). 30초 제한으로 종료, 정상 정차·장치 반환·누락 0 확인. 사용자가 정차·입력 해제를 확인했다. 감시기의 `time_limit`이 제어기의 `duration_complete`보다 약 10ms 먼저 기록되므로, 정상 시간 제한 종료를 데이터 적격 조건에 명시했다. F8·오류·미시작 종료는 적격으로 바꾸지 않았다.

## 2026-10-01 — 교사 자료 확정과 오프라인 학습

- 교사 2회 [validation 실행](../actuator_runs/demo-1790830785710827500-10312/summary.json), 3회 [test 실행](../actuator_runs/demo-1790831109761242900-5124/summary.json)을 확보했다. 세 실행 모두 정상 시간 제한·정차·장치 반환·누락 0이며 사용자도 입력 해제를 확인했다. test 대기 만료 시도 [기록](../actuator_runs/demo-1790830888759982100-11592/summary.json)은 제외했다.
- accepted 명령 행에는 전송 축 값이 비어 있다는 사실을 준비 중 발견했다. 별도의 성공 전송 행을 명령 sequence로 연결하도록 수정했다. 최초 실패 준비 폴더는 미완료로 보존했다. 정답은 계속 PID 요청이며 전송/관측은 비교값이다.
- [확정 학습 자료](../training_datasets/teacher-1790831274127801600-3f9a62c4/manifest.json): train 23,135, validation 503, test 503. 원래 한 바퀴 119,234개 대응 관측 중 22,629행을 채택했고 추가 train은 506행이다. 특징 부족·50ms 선택·모호한 대응의 제외 근거는 excluded.csv에 있다.
- train 가속/제동/무입력은 1,613 / 21,458 / 64, validation은 7 / 493 / 3, test는 38 / 458 / 7이다. 가속·무입력의 짧은 검증 표본 수와 validation/test 오르막 0행을 한계로 남긴다.
- [정식 학습](../training_runs/train-1790831348972059200-86f67d6c/summary.json): 89 epoch, epoch당 91회·총 8,099회 optimizer 갱신, 20 epoch 조기 종료. best=69, validation weighted Smooth L1=0.0003931. test로 모델을 선택하거나 설정을 조정하지 않았다.
- [재생 평가 보고서](../evaluation_runs/test-1790831417858521800-5c57f8f8/report.html), [실게임에 사용한 배포 모델](../trained_models/policy-1790831733844800700-f1c69f75/manifest.json). validation/test 모두 정해진 MAE/p95·세 집단 존재·중앙값 기준 비교를 통과했다. 모델을 적용한 차량 응답의 재현이나 일반화 검증은 아니다.
- 작업용 sources/config와 구현 파일은 스냅샷/실행 당시 해시로 기록하고, 원본·완료 산출물 해시와 구분했다. 초기 smoke 결과는 이전의 가변 소스 해시 방식으로 생성되어 이후 로더 재검증 근거로 쓰지 않는다. 원래 실행 당시의 동작 검사 기록으로만 보존한다.

## 2026-10-01 — 재개·추론·실시간 연결

- 합성 학습에서 동일 seed 반복 학습과 2+2 epoch 재개가 연속 4 epoch와 파라미터 단위로 같았다. epoch 도중 중단은 마지막 완료 epoch를 보존하며 재개 후 연속 실행과 일치했다. 저장 실패·변조·출력 충돌·미완료 로더 거절도 확인했다.
- 최초 전체 회귀: Rust 105개 통과 / 장치가 필요한 1개 무시, Python 108개 통과. fmt/clippy 통과. 컴파일 중 Health의 RPM 추가에 따른 기존 시험 fixture 누락을 고쳤다. 이력 손실 중단 이유가 일반 missing prediction으로 덮이는 검사 실패도 최초 원인을 보존하도록 수정했다.
- Python/Rust 모델은 같은 float32 계층·정규화와 순서를 사용한다. 페달 변환 마지막 곱셈은 f64로 수행해 가속 상한 0.20을 f32 반올림으로 초과하지 않도록 했다. 비유한 중간 계층도 실패 처리한다.
- [최초 shadow](../actuator_runs/demo-1790831750335748000-17816/summary.json): 정상 종료·정차·반환·누락 0, 모델 전송 0, 추론 p99 20µs(10µs histogram 분해능). 사용자 확인 완료.
- [최초 5초 시도](../actuator_runs/demo-1790831942943280500-18696/summary.json)는 `policy_handoff_timeout`으로 중단됐다. 모델 담당 시간 0이며 5초 시험 성공이 아니다. 사용자는 정차·입력 해제를 확인했다.
- 원인: worker가 계산 후 별도로 10ms 대기하여 100Hz 관측과 위상이 어긋났다. 기록된 고유 관측 간격 중 약 20ms가 170회 나타났고 최대 20.8127ms였다. 과거 조회 허용 20ms를 넘는 순간이 반복돼 연속 1초 인계 확인을 충족하지 못했다.
- 수정: policy 실행에서만 새 감시기 관측을 즉시 처리하고, 없을 때 1ms 대기한다. 최신 관측 슬롯을 유지해 명령을 쌓아 재생하지 않는다. PID 이득·모델 가중치·20ms/1초/10초 조건은 바꾸지 않았다. 수정 후 재검증을 이어간다.

- 세 실행 모두 `policy_duration_complete`, 정상 정차·장치 반환·누락 0이며 모델 요청과 실제 전송 명령의 출처를 대조했다. 5초·15초는 사용자 정차·입력 해제 회신도 받았다. 10초는 사용자의 시간 검증 요청에 따라 텔레메트리의 정차·반환 및 제어 주체 이벤트로 확인했다.
- 위 시간은 첫 모델 관측부터 첫 중단 관측까지다. 초기 raw summary의 `policy_model_elapsed_ns`는 정차 확인 꼬리 시간까지 포함했으므로 그대로 모델 담당 시간으로 사용하지 않았다. [독립 재계산](../Evaluator/live.py)으로 구분했고, 이후 실행의 summary와 중단 이유 표시도 수정했다. 기존 원본 결과는 수정하지 않았다.
- 모델/PID 차이 중단, 이력 손실 중단, 조기 종료·재개는 자동 검사로 확인했다. 장치 고장 상황에서 제동을 보장한다고 주장하지 않는다.
- 최종 Rust **107개 통과 / 장치 의존 1개 무시**, Python **110개 통과**, fmt/clippy/release 빌드 통과. 추가 검사는 모델 구조·해시·미완료·비유한 중간값, 모델 제어 시간과 정차 꼬리 분리, shadow/명령 출처 불일치 검출을 포함한다.
- [자료 재생성](../training_datasets/teacher-1790832290696260600-22680b1c/manifest.json)의 train/validation/test JSONL·normalizer·excluded.csv가 최초 결과와 모두 바이트 일치했다. 원본 해시 재검사도 통과했다. [최종 내보내기](../trained_models/policy-1790832608550966200-477cadb0/manifest.json)의 model.json은 실제 주행에 쓴 모델과 바이트 일치하며 단위·출력 변환 메타데이터를 추가했다. Python/Rust 최대 예측 차이는 **3.087701797×10⁻⁸**이었다.
- 내보내기 도중에는 미완료 상태를 유지하고 별도의 `predict-candidate` 수치 대조만 허용한다. 실제 입력 로더는 미완료 모델을 거절한다. 모든 출력 저장 이후에만 완료 상태가 된다.
- [통합 보고서](../evaluation_runs/integration-1790832864652455200-4441a208/report.html), [기계 판독 검증 근거](../evaluation_runs/integration-1790832864652455200-4441a208/verification.json). 해당 집계는 원본을 다시 검사해 재생성할 수 있다.
- 최종 문서·산출물 점검: 로컬 근거 링크 121개, HTML 7개·SVG 85개 구조 검사 오류 0. 자료/학습/두 배포 모델/통합 결과의 입력·출력 해시 재검사 통과. 종료 후 actuator 프로세스 0개를 확인했다. 브라우저의 모든 인쇄 레이아웃을 육안 검증한 결과로 표현하지 않는다.

## 완료 범위와 후속 과제

**저속 교사 모방의 자료 준비 → 학습·재개 → 고정 모델 → Rust 추론 → 5/10/15초 실제 가감속 → 정상 정지·입력 해제 흐름을 완료했다.**

목표 10km/h에 비해 모델 구간 약 10.94~11.67km/h의 오차가 남아 있다. 다음 분석에서는 요청·전송·관측 페달과 경사, PID 내부 적분 상태를 현재 특징이 얼마나 설명하는지 검토한다. 검증/평가의 오르막 0행, 가속·무입력 소표본 한계도 보완 대상이다. 같은 test를 반복 최적화하는 자료로 바꾸지 않는다.

사람 고속 모방학습, 모델 한 바퀴 완주, PID 성능 향상, 독립 일반화 성능, 온라인 학습과 장치 장애 대응은 미완료로 유지한다. 현재 결과를 더 긴 주행이나 고속 제어 허가로 확대하지 않는다.
