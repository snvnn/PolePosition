# TrackModel 개발 기록

## 2026-09-29 — 착수

- 목표: 검토를 통과한 train 중 최단 랩으로 재생성 가능한 기준 주행선을 만든다. 사용자 선택은 가장 빠른 실제 1랩이다.
- 입력은 기존 확정 검토 결과이며, 현재 예상 선택은 5번 랩·89.170초다. 보류·validation·test는 선택과 설정 결정에 사용하지 않는다.
- Python 3.11 표준 라이브러리, TOML 설정, 고유 출력 폴더와 검증된 파일 로더를 구현한다.
- 계획 중 계산한 시작·끝 차이 약 1.39m와 평활 이동 약 4.9cm는 타당성 조사다. 구현·자동 테스트·실제 결과 검증은 아직 완료하지 않았다.
- 개발 순서: 입력/선택 → 경로 계산 → 보고서/로더 → 합성 및 통합 검사 → 실제 경로 시각 검토. 실행 결과는 아래에 추가한다.

## 2026-09-29 — 입력 검증과 랩 선택

- [inputs.py](../TrackModel/inputs.py)는 확정 판정의 원본 해시, 검사 결과 해시, 판정 복사본, 데이터셋과 검사 랩 목록을 대조한다. 기존 원본/랩 CSV 검증기를 재사용한다.
- DatasetBuilder 검토 모듈에서 집합별 사용 목록 계산을 부작용 없는 `decision_usage()` 함수로 분리해 finalize와 TrackModel이 같은 규칙을 사용한다. 기존 데이터 파일은 변경하지 않았다.
- 유효 train 목록을 판정에서 다시 만들고 usage.json과 비교한다. 후보의 정수 나노초 랩 시간이 최솟값인 랩을 선택하고 동률이면 원본 시작 순서로 결정한다.
- 학습 후보가 없거나 판정/목록이 다르면 실패한다. 선택 랩의 경로가 부적합해도 다른 후보로 교체하지 않는다.

## 2026-09-29 — 경로 계산과 품질 보고

- [geometry.py](../TrackModel/geometry.py)에 시간순 좌표 정리, 폐곡선 거리 재표본화, 순환 2차 최소제곱 평활화, 재표본화 후 실제 거리, 접선 및 부호 곡률을 구현했다.
- 평활화는 중심점과의 좌표 차이로 계산해 큰 월드 좌표에서 불필요한 정밀도 손실을 줄였다. X–Z 거리와 방향을 계산하고 Y도 같은 순서로 보존·평활화한다.
- 평활 이동량·길이 변화·간격·연결부 포함 방향 변화 상한은 승인된 기본값 그대로다. 과도한 점 수 요청은 1,000,000점에서 제한한다.
- [report.py](../TrackModel/report.py)는 원래/생성 궤적에 하나의 좌표 변환을 사용한다. 출발선의 관측 공백은 붉은 점선으로 구분하고 전체 및 앞뒤 30m를 표시한다. 높이·연속 표시 방향각·곡률·이동량 그림도 포함한다.
- [model.py](../TrackModel/model.py)의 로더는 원본 세션 없이 출력 폴더만으로 사용 가능하다. 해시·필수 열·좌표 규약뿐 아니라 좌표에서 거리·접선·곡률을 다시 계산해 저장 값과 대조한다.

## 2026-09-29 — 합성 및 회귀 검증

- TrackModel 최초 20개 테스트가 모두 통과했다. 이후 매우 작은 목표 간격의 점 수 제한과 출발선 확대 그림의 원본 연결선 구분을 보강했다.
- `python -m unittest DatasetBuilder.test_builder DatasetBuilder.test_report DatasetBuilder.test_review TrackModel.test_model -v`: **67개 통과**(기존 47 + TrackModel 20).
- 원/역방향 원의 길이·접선·곡률 부호, 불균일 간격·중복 좌표, 퇴화·비유한 값·큰 닫힘 간격, 가까운 평행 구간의 원본 순서 보존을 검사했다.
- 모든 품질 상한을 강제로 초과시키는 검사, 최단 랩·동률·보류/집합 차단, 후보 없음, 판정 복사본·사용 목록·원본·검사 변조 및 실행 중 입력 변경 검사를 통과했다.
- 반복 생성 바이트 일치, CSV 재읽기, 미완료/지원하지 않는 결과 거절, 출력 충돌과 입력 폴더 보호, 저장 실패 진단을 확인했다. 합성 보고서의 SVG 6개 파싱·로컬 링크 검사도 통과했다.
- 아직 이 항목만으로 실제 경로 검토를 완료 처리하지 않는다. 실제 생성 및 시각 검토 결과는 아래에 별도 기록한다.
