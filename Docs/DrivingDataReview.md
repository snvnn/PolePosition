## 검토 방법과 한계

승인된 기본 임계값으로 검사했으며 결과에 맞춰 변경하지 않았다. train 7랩만 기준 계산에 사용하고
train 자신의 검사에는 자기 랩을 제외했다. 6랩에서 14개 후보가 나왔고 5랩에는 후보가 없었다.
기준 자료 부족, 역행, 지속 저속, 위치 도약 후보는 없었다.

후보가 있는 랩부터 각 후보 전후 3초의 궤적·속도·가속·브레이크·원시 조향을 확인했다.
후보가 없는 랩도 포함하여 11랩 전체의 궤적과 진행률별 네 신호를 확인했다.
검토 보고서의 SVG를 독립 문서 렌더러로 이미지화한 전체 랩 11개와 후보 문맥 14개를 육안 확인했다.
SVG 125개는 구조 파싱을 통과했다. 이 검증을 HTML 브라우저 배치·링크 클릭·인쇄 검증으로 표현하지 않는다.

모든 후보는 통계적 차이로서 해석했다. 순간적인 패드 조향 보정과 감속 시점 차이만으로 접촉이나 스핀을
판정하지 않았다. 일반 출발선 통과와 핫랩 차량 상태 초기화도 사고 근거로 사용하지 않았다.
사용 가능은 이 검토 범위에서 사용을 막는 문제가 확인되지 않았다는 뜻이다. 무사고 증명은 아니다.
도로 경계·충돌 상대·접촉 여부 등 필요한 정보가 없어서 궤적 적합성이 불분명한 랩은 보류했다.
현재 결과는 **단일 세션의 데이터 품질 점검**이며 독립적인 모델 성능 평가가 아니다.

## 후속 전달과 재생성

TrackModel 후보 전체 ID는 다음과 같다. 대표 기준 경로를 아직 선택하거나 생성하지 않았다.

```text
1790669289916063400-33768-0-s2-q6361
1790669289916063400-33768-0-s2-q24558
1790669289916063400-33768-0-s3-q37852
1790669289916063400-33768-0-s3-q46818
1790669289916063400-33768-0-s5-q101962
```

사용 가능 분리는 train 5 / validation 1 / test 3이며 train 2랩은 보류다.
검증·평가 랩을 train으로 이동하거나 기준 경로 선택에 사용해서는 안 된다.
보류 6·10번은 원본과 기존 train 목록에는 남지만 이번 후속 사용 목록에는 포함하지 않는다.
그 밖의 train 후보가 있으므로 이번 작업을 끝내기 위해 사용자에게 불확실한 사고 원인을 확인받을 필요는 없다.

```powershell
python -m DatasetBuilder.review finalize --review reviews/scan-1790674428796657400-4cac817c --decisions reviews/scan-1790674428796657400-4cac817c/decisions.reviewed.json
```

위 명령은 새 확정 폴더에 같은 판정과 후속 목록을 생성한다.
반복 검사에서 기준·후보·HTML·초안의 바이트가 같았고 반복 확정의 판정·사용 목록도 바이트가 같았다.
자동 테스트 **47개 통과** 및 입력 변조·출력 충돌·저장 실패 검증 상세는
[개발 기록](DatasetBuilderDevelopmentLog.md)에 있다.

다음 작업은 이 5개 학습 후보를 입력으로 사용하는 TrackModel 설계·구현이다.
도로 중심선 추정, 상태 구성, 학습과 차량 제어는 이번 검토의 구현 범위에 포함하지 않았다.
