- 검증 결과: [validation-1790671157264434400.json](../recordings/1790669289916063400-33768-0/validation-1790671157264434400.json).
- 세 랩 모두 구간 8이며, 시작 `elapsed_ns`는 순위순으로 `1746660086100`, `1480210114900`, `1657780093700`이다. 완주 순번은 이 세션에서 검증된 완전한 랩 목록 기준이며 게임의 완료 랩 카운터와 구분한다.

## 개발 레퍼런스

### ACC 공유 메모리 — 1단계 텔레메트리 수집

- 저장소: [rrennoir/PyAccSharedMemory](https://github.com/rrennoir/PyAccSharedMemory)
- 참조 소스: [src/pyaccsharedmemory.py](https://github.com/rrennoir/PyAccSharedMemory/blob/main/src/pyaccsharedmemory.py)
- 참조 용도: ACC 공유 메모리의 필드 순서, 자료형, UTF-16 문자열 및 패딩, 차량 ID와 좌표 배열의 대응 확인.
- 프로젝트 적용: TelemetryDataServer의 Physics·Graphics·Static 파싱 구현. 사용한 오프셋과 실제 확인 범위는 [RecordingSpecification.md의 ABI 근거](RecordingSpecification.md#abi-근거)에 정리했다.
- 참조 관계: 외부 공개 구현을 구조 대조 자료로 사용했으며, 해당 Python 패키지를 런타임 의존성으로 사용하지 않는다. 현재 수집기는 Rust에서 Windows 공유 메모리를 직접 읽는다.
- 위 링크는 변경 가능한 main 브랜치 기준이다. ACC 버전이나 필드를 변경할 때 자료와 실제 게임 값을 다시 대조한다.
