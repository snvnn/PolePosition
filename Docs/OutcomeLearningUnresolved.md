# 성공과 실패 기록 학습의 적용 범위와 미확인 사항

2026년 10월 31일 기준. 원본 기록, 최초 무개입 2랩 성공 모델, 이후 후보 모델은 보존한다. 새 모델은 오프라인 후보이며 현재 GUI의 모델을 자동 교체하지 않는다.

## 확인된 자료로 구현한 범위

- A는 교사 입력과 확인된 무개입 성공 구간을 모방하는 비교 모델이다. B는 같은 모방 손실에 IQL 방식으로 계산한 행동 가치 가중 회귀를 추가한다. 실패 입력에 음수 모방 가중치를 주지 않는다.
- 두 후보는 같은 수정 경로, 연속 교사 28랩 기준 속도, 사람 학습 표본만으로 계산한 정규화, 35개 특징과 3개 패드 행동을 사용한다. 이전 입력, 엔진 상태, 종방향 반응 특징의 제외 설정을 유지한다. 각 출처의 옛 특징을 섞지 않고 원시 위치에서 다시 계산한다.
- 실행 배우는 128×128 은닉층, 조향 tanh, RT/LT sigmoid를 유지한다. Q 두 개와 V는 오프라인 학습에만 사용한다. 실행 중 학습이나 탐색은 추가하지 않는다.
- 학습·검증은 세션 단위로 분리한다. 무개입 성공 두 랩과 같은 세션의 세 번째 실패 랩은 모두 학습 쪽에 둔다. 동일 로그의 복사본은 분리된 자료로 취급하지 않는다.
- 정상 정지까지 검증된 사람 교정 기록은 기존 검증기를 통과한 축만 모방한다. 조향 개입은 `[1,0,0]`, 전체 개입은 `[1,1,1]` 마스크를 유지한다. 마지막 검증 통과 교정 세션은 별도 검증에 둔다. 중단된 교정 기록을 임의로 복구하지 않는다.
- 실패는 **연속된 정상 관측에서 ACC의 랩 유효성이 true에서 false로 변하고, 그 시각까지 모델 입력이 전송되고 있었으며 안전 제동은 아직 시작되지 않았음**이 확인된 경우만 사용한다. 실패 기록의 앞부분 전체에 실패 벌점을 붙이지 않는다.
- 성공·실패 분류와 종료 유형은 목표·출처 정보이며 모델의 관측 입력에 넣지 않는다. 보고서의 `failure_trajectory`는 실패로 끝난 기록의 비성공 구간이라는 출처 분류이지, 각 행동이 잘못됐다는 라벨이 아니다.
- 전송 보고서와 XInput 피드백, 20ms 이내의 관측→명령 전송, 실제 이후 관측, 원본 순서·시간·추적 구간을 검사한다. 마지막 실제 관측이 없으면 가짜 종료 경험을 생성하지 않는다.
- 타깃은 `r + gamma^(dt/0.02) * (1-terminated) * V(next)`다. 확인된 랩 완료와 랩 무효화만 종료 보상을 받는다. 수동 재시작·F8·통신 문제·원인 불명 종료를 실패로 추정하지 않는다. 이번 자료에서 그런 세션은 경험 묶음에 추가하지 않는다.
- 공통 모방학습 40epoch의 최적 체크포인트에서 A와 B를 각각 10epoch 갱신한다. 두 후보의 모방 표본 선택, 초기 배우·최적화 상태, 배우 갱신 횟수는 같다. B의 Q/V만 추가로 20,000회 갱신한다. 시간 표본 증강은 보존하되 이번 비교에는 새 관측 잡음을 추가하지 않는다.
- IQL 초기 설정은 expectile 0.7, advantage temperature 3, 배우 가중치 상한 20, 20ms당 할인율 0.999, 타깃 갱신 0.005다. 배우 손실은 모방 손실 + 0.1×가치 가중 회귀다. CPU, seed 42, 배치 256, Adam 0.0003을 사용한다.

## 격리 정책

숨김은 학습 포함 목록에서 제외한다는 뜻이다. 파일을 삭제하거나 이동하지 않는다. `quarantine.json`, `run-audit.json`, `transition-audit.json`, `correction-audit.json`에 원본과 사유를 남긴다.

1. 시작 시 기준 경로의 출발선 양쪽 150m 안에 있는 세션·실제 재시작 구간은 그 범위를 벗어날 때까지 제외한다. 이후 620ms도 제외해 기존 특징 이력이 격리 구간을 참조하지 못하게 한다. 620ms는 공유 Rust 특징 엔진의 최대 이력 보존 시간이다. 정상 연속 랩의 출발선 통과는 이 규칙에 해당하지 않는다.
2. 이미 출발선 위빙을 분석한 `gamepad-1793424022562561400-52032`, `gamepad-1793424064023111200-5944`는 전체 세션을 격리한다. 정밀한 위빙 시작·종료 경계는 확정하지 않는다.
3. 현재 선택된 4개 교사 세션에서 출발선 ±150m 출발 조건에 해당하는 구간이 없으면 표본을 억지로 제거하지 않는다. 핫랩 세션의 고유 시작 위치와 실제 랩 출발선은 다르다. 핫랩 시작 위치의 자료까지 모두 제거하라는 뜻으로 확대 해석하지 않는다.
4. 모방학습에 쓰지 않는 과거 기록도 감사 목록에 남긴다. 장치 응답 검사·미완료 폴더는 실패 주행으로 계산하지 않는다.

| 독립적인 성공 가치 검증 | 성공 두 랩은 같은 세션의 학습 자료다. 독립 성공 검증 세션이 있다고 주장하지 않는다. | 별도 무개입 완주 세션 |

## 보상과 검증의 해석

초기 원시 보상은 기존 계획의 `Δs − 0.1Δt − 0.2e_lat²Δt − 0.1e_heading²Δt − 0.01‖Δa‖² + 종료 보상`을 사용한다. 완주 +10, 관측된 랩 무효화 −10이다. 입력 변화는 전송된 축을 사용하고 후진은 음의 진행으로 계산한다. 학습 때 원시 보상에 0.01을 곱하며 항목별 원시 보상도 남긴다. 랩 완료는 이 실험의 에피소드 종료로 취급한다. 할인율의 유효 범위는 대략 수십 초이므로 이를 완주 보상의 최적 설계라고 간주하지 않는다.

기존 교사 검증 세션은 이미 모델 선택에 사용됐다. 보류된 실패 세션의 TD 오차는 가치 학습 진단이며 실제 안전성 지표가 아니다. 실패한 조작과 예측이 비슷해졌다는 이유로 성능이 좋아졌다고 평가하지 않는다. 성공과 실패의 관측 상태가 다르므로 단순한 평균 Q값 차이도 인과적 개선 증거가 아니다.

새 후보의 모델·체크포인트·설정·데이터 해시·수치 대조·평가 보고서를 보존한다. 자동 GUI 승격, F7 입력, 온라인 SAC 연결, 자동 초기화는 추가하지 않는다. 실제 주행은 별도 시험 단계이며 미검증 상태로 둔다.

알고리즘 근거: [Offline Reinforcement Learning with Implicit Q-Learning](https://arxiv.org/abs/2110.06169). 본 구현은 기존 결정론적 게임패드 배우를 유지하는 가치 가중 회귀 변형이며, 논문 벤치마크 성능을 이 게임의 성능 근거로 사용하지 않는다.
