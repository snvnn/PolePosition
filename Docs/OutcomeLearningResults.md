# 성공과 실패 기록 학습 결과

2026년 10월 31일. 실패 경험을 포함한 B와 모방학습 비교 모델 A를 생성했다. 현재 GUI의 최초 무개입 2랩 성공 모델은 유지했다. 아래 결과는 오프라인 검증이며 실주행 개선 판정이 아니다.

## 모델과 실행 설정

| 구분 | 산출물 |
|---|---|
| A 모방학습 비교 모델 | `reinforcement_runs/gamepad-outcome-a-release-1793428298142416600-e4c7055f` |
| B 실패 경험 포함 후보 | `reinforcement_runs/gamepad-outcome-b-release-1793428298259417400-d7511d7d` |
| 비교 평가 | `reinforcement_runs/outcome-evaluation-1793428298102915600-dcca11dc/comparison.json` |
| 최종 데이터 | `reinforcement_runs/outcome-dataset-1793427949689917000-24577921` |
| 학습 이력과 Q 두 개 및 V | `reinforcement_runs/outcome-training-1793428050538418200-714d17de` |
| B 연속주행 GUI 프리셋 | `TrainingController/outcome-b-continuous-preset.json` |
| B 5초 GUI 프리셋 | `TrainingController/outcome-b-5s-preset.json` |
| A 연속주행 GUI 프리셋 | `TrainingController/outcome-a-continuous-preset.json` |

A와 B 모두 수정 경로와 연속 랩 기준 속도를 사용한다. 배우의 총 학습 계산은 각각 44,800회이며 B의 가치 함수만 20,000회 추가 갱신했다. 최종 가중치는 공통 모방학습의 최적 상태에서 분기한 10epoch 중 교사 검증 MSE가 가장 낮은 상태를 선택했다. A는 분기 후 6epoch, B는 4epoch가 선택됐다. 이전 입력·엔진 상태·종방향 반응 특징 제외는 유지했으며, 실행 모델·행동 구조는 기존 게임패드 형식과 같다.

## 사용한 자료

- 교사 학습 401,369개, 교사 검증 27,514개.
- 무개입 성공 2랩 9,090개. 학습 세션이며 독립 성공 검증 자료는 아니다.
- 검증된 사람 교정 학습 6,455개, 마지막 교정 세션 검증 1,064개. 조향 개입은 조향 축만 정답으로 사용했다.
- 결과 경험 80,609개를 세션 단위로 학습 67,320개와 검증 13,289개로 분리했다. 학습 경험에는 성공 2랩이 포함되므로 위 성공 표본과 별개 주행량으로 합산하면 안 된다.
- 확인된 실패 종료는 학습 47회, 검증 12회다. 성공 완료 보상은 학습 2회다. 각 경험 전체에 벌점을 주지 않고 실제 무효화 종료에만 종료 벌점을 부여했다.
- 이전에 분석한 위빙 두 세션은 통째로 격리했다. 현재 선택된 교사 세션에는 기준 출발선 ±150m에서 시작한 구간이 없어 출발선 출발 규칙으로 추가 제거된 교사 표본은 0개다.

115개 완료 게임패드 주행 요약 외에 미완료·장치 검사 폴더도 감사 목록에 포함됐다. 62개 기록에서 주행 중 유효→무효 전환을 확인했고, 명령 필드가 없는 구형 기록 2개와 새 특징 이력을 온전히 만들지 못한 기록 1개를 추가 제외해 59개 세션의 경험을 사용했다. 사람 교정 자료는 이 실패 경험과 별도로 기존 검증기를 통과한 14개 세션에서 가져왔다.

## 같은 교사 검증 관측의 오차

MSE는 낮을수록 교사 입력과 가깝다는 의미이며 안전성이나 완주율이 아니다. 최초 모델에는 당시 경로의 특징, A·B에는 새 경로의 특징을 사용해 같은 원본 관측과 정답 입력을 비교했다.

| 모델 | 조향 MSE | RT MSE | LT MSE | 출발선 ±15m 조향 MSE |
|---|---:|---:|---:|---:|
| 최초 무개입 2랩 성공 | 0.01427150 | 0.01117404 | 0.01533541 | 0.00696956 |
| A | 0.01550132 | 0.01171513 | 0.01510146 | 0.00708452 |
| B | 0.01509547 | 0.01190186 | 0.01512285 | 0.00482832 |

B는 A보다 전체 3행동 평균 MSE가 0.47%, 출발선 ±15m 조향 MSE가 31.85% 낮다. 최초 성공 모델과 비교하면 출발선 조향 MSE는 30.72% 낮지만 전체 평균 MSE는 3.28% 높다. 해당 출발선 소구간은 검증 표본 81개이므로 이 수치만으로 위빙 개선을 확정할 수 없다. 문제 코너 550~950m의 B 조향 MSE는 0.01533389로 최초 성공 모델의 0.01479567보다 높다.

실패 궤적 표본의 배우 가중치는 평균 1.0239, 성공 표본은 1.0256이었다. 실패 궤적 전체가 일괄적으로 낮은 가중치를 받은 것은 아니다. IQL 가중치는 각 상태에서 기록된 행동의 추정 상대 가치를 반영한다. 실패 표본을 많이 넣었다는 사실만으로 잘못된 행동이 충분히 억제됐다고 주장하지 않는다.

## 확인한 항목과 남은 시험

모델별 49,893개 입력을 Python과 Rust에서 대조했다. 최대 절대 오차는 A `1.1924e-6`, B `9.3282e-7`로 `1e-5` 기준을 통과했다. 배우 체크포인트 복원 후 예측이 정확히 일치했고, B의 Q 두 개·타깃 Q 두 개·V 상태도 저장된 학습 상태와 일치했다. 데이터 파일과 원본 로그 해시, 세션 분리, 마지막 관측, 종료 보상, 정규화 자료, GUI 프리셋의 모델·경로 연결을 검사했다.

원본 기록, 최초 성공 모델, 이전 후보 모델은 보존돼 있다. 새 후보는 GUI 프리셋만 준비했으며 실행 중인 모델을 교체하거나 F7을 입력하지 않았다. 정차 출발·문제 코너·출발선 연속 통과와 정상 정지·해제는 실제 시험이 필요하다.

미확인 사항의 처리와 구현하지 않은 판단은 [성공과 실패 기록 학습의 적용 범위와 미확인 사항](OutcomeLearningUnresolved.md)에 정리했다.

## 재현 명령

저장소 루트에서 `.venv-training/Scripts/python.exe`로 다음 모듈을 순서대로 실행한다. 각 단계는 출력한 새 폴더를 다음 단계에 전달한다.

1. `-m TrainingEnvironment.outcome_data TrainingEnvironment/outcome-experiment.json`
2. `-m TrainingEnvironment.build_outcome_dataset <감사 단계 폴더>`
3. `-m TrainingEnvironment.outcome_corrections <완료된 데이터 폴더>`
4. `-m TrainingEnvironment.verify_outcome_dataset <교정 자료 포함 폴더>`
5. `-m TrainingEnvironment.outcome_learning <교정 자료 포함 폴더>`
6. `-m TrainingEnvironment.evaluate_outcome <완료된 학습 폴더>`

감사는 실행 시점의 주행 폴더를 조사한다. 이번 표본 구성을 그대로 재현하려면 위 최종 데이터의 해시로 고정된 자료를 사용한다. 새로 쌓인 주행까지 추가되면 같은 실험의 재실행이 아니라 새로운 데이터 실험이다.
