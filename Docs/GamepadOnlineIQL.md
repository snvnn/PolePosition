# B 연속주행 IQL — 구현 및 오프라인 검증

2026-10-31. 사용자의 요청에 따라 이번 실행은 코드와 오프라인 검사까지만 수행했다.
실게임 첫 회차, 다음 F7에서 새 정책 적용, 고정 정책 3랩 × 3회 평가는 **미실시**다.
오프라인 검사 통과는 주행 안정성 통과가 아니다.

## 실행 경로

`TrainingEnvironment/gamepad_online.py` → 상주 `poleposition-gamepad --supervise` → F7 수동 시작 → 계속주행 → 종료 사건 → 정차/해제 → 경험 검증 → IQL → 후보 저장/복원/수치 대조 → 다음 수동 F7.

- 기존 vJoy SAC 경로와 분리했다. 속도 단계, 회차 시간 제한, 탐색, LPF를 추가하지 않았다.
- 첫 출발선 통과는 접근 완료다. 이후 유효한 한 바퀴마다 +10이며 주행은 계속한다.
- 연속 관측의 유효→무효 전환, 최근 실제 관측 10초 순전진 0.5m 미만을 별도 종료 사건으로 기록한다.
- 주행 종료 `episode_end`와 정차 결과 `shutdown`을 분리했다. 기존 `reason`은 이전 결과 도구와의 호환용이므로 학습 판정에 사용하지 않는다.
- 추적 구간이 바뀌면 정차 확인 시간을 초기화한다. 새 구간의 준비된 관측에서 1km/h 이하 0.5초를 확인하고 중립화·장치 해제를 확인한다. 이를 정상 연속 제동으로 표현하지 않는다.
- F8/GUI 중지/오류/사람 개입 회차는 자동 학습하지 않는다. F7은 학습 중 버리며 예약하지 않는다.
- 세션 2시간에는 준비·학습이 포함된다. 시간 만료 시 안전 정지와 원본 기록 마무리를 기다리며 추가 갱신을 시작하지 않는다. 시간 만료 원인은 세션 요약의 `truncated`로도 표시한다.

## 데이터와 학습

`gamepad_online_data.py`는 기록 무결성, 인과적인 실제 전송·다음 관측, 입력 유지, 추적/sequence 연속성, 유한값, 최종 관측과 정차 기록을 검사한다. 준비/정지/재배치 구간은 replay에 넣지 않는다. 원시 입력·관측은 원본 로그에 보존한다.

기존 격리 목록과 출발선 ±150m 출발 제외 및 이력 준비 여유 620ms를 유지한다. 이 규칙은 위빙이나 복귀 성공을 자동으로 판별하는 규칙이 아니다. 기존 raw 기록 및 모델은 수정하지 않았다.

배포 B `gamepad-outcome-b-release-1793428298259417400-d7511d7d`의 실제 checkpoint를 읽는다. 과거 데이터 생산용 `config.source_model`은 시작 배우로 사용하지 않는다. 기존 train replay에서 실제 다음 관측이 있는 정상 완주의 +10을 유지하면서 비종료로 바꾼 파생 `continuous-seed-replay.json`을 만든다. validation은 가치/배우 배치에서 차단한다.

- 배우를 고정한 Q/V 20,000회 보정 완료. 초기 배우 파일 SHA-256은 B와 동일하다.
- CPU, 기존 128×128 구조·정규화·제외 특징·경로·기준 속도와 Adam 상태를 유지한다.
- IQL 보상 배율 0.01, 20ms 할인율 0.999, expectile 0.7, advantage temperature 3, 가중치 상한 20, target tau 0.005를 유지한다.
- 온라인 replay 200,000개, 가치 배치 기존/온라인 128개씩. 온라인 256개 미만은 저장만 한다.
- Q/V `min(미반영 경험 // 4, 500)`, 배우는 Q/V 4회마다 갱신한다. 기존 교사·검증된 교정·성공 표본의 모방 손실 + 0.1 × 가치 가중 회귀다.
- 경험을 먼저 별도 불변 폴더에 확정한다. 후보의 모델/critic/targets/V/최적화/RNG/replay/설정/계보를 저장하고 재읽기·유한값·해시·출력 대조를 통과해야 `latest.json`을 원자적으로 교체한다.
- 중단 후 세션 폴더에서 재개하면 마지막 완료 checkpoint와 아직 checkpoint에 들어가지 않은 완료 경험을 복구한다. 미완성 경험/후보는 실행하지 않는다.
- 대용량 JSON을 나눠 읽고 저장하여 준비·저장 중 관리 연결의 응답을 유지한다.

## GUI 설정

기존 창을 재시작하면 강화학습 그룹에 `게임패드 회차 학습`, `고정 정책 연속주행 평가`가 나타난다.

- `B에서 새 학습 준비`: B의 배우/critic에서 새 세션을 만든다.
- `온라인 체크포인트에서 재개`: checkpoint 또는 세션 폴더를 사용한다. 경험 복구를 위해 세션 폴더 선택을 권장한다.
- `TrainingController/gamepad-online-preset.json`: 이미 가치 보정과 검증을 마친 초기 B 세션을 선택한다. 프리셋만 열어서는 주행하지 않는다. 추후 사용자가 준비 후 재개 버튼, 스틱 선택, F7 순서로 시작한다.
- `TrainingController/gamepad-online-evaluation-preset.json`: 현재는 초기 B를 고정 정책 평가 대상으로 지정한다. 학습 후 평가할 때는 검증된 새 checkpoint를 선택한다.
- 첫 통합 검증 설정은 `max_episodes=1`이었다. 현재 `max_episodes=0`은 회차 제한 없이 전체 시간 제한까지 학습하며, 양수는 지정 회차에서 종료한다. 고정 정책 평가는 계속 3회로 제한된다.
- 평가에는 replay 추가/학습이 없다. 같은 정책으로 3랩을 3회 완료하고 각 정차/해제를 확인한다. 출발 조건은 같은 기어·정차 상태와 첫 평가 위치에서 1m 이내로 검사한다. 이 1m는 비교 재현성 허용 오차이며 경로 이탈 제한이 아니다.
